Available Commands

Usage: getblockcount

Returns the current block count in the longest blockchain.

Usage: getmempoolinfo

Provides information about the transaction memory pool (mempool).

Usage: getdifficulty

Returns the current proof-of-work mining difficulty.

Usage: getchaintxstats [nblocks] [blockhash]

Returns statistics about chain transactions, such as the rate and count.

Usage: listwallets

Lists all open wallets loaded by the node.

Usage: listaccounts [minconf=1]

Lists accounts and their balances. (Note: Deprecated in favor of labels).

Usage: getwalletinfo

Returns summary information about the wallet, including balances and transaction counts.

Usage: getbalance [dummy="*"] [minconf=1] [include_watchonly=false]

Returns the total available balance of the wallet.

Usage: abandontransaction "txid"

Marks a wallet transaction as abandoned. This only affects internal wallet state, not the blockchain.

Usage: pruneblockchain <height>

Deletes old blocks from the local blockchain data to save disk space. Requires the node to be in pruning mode.

Usage: issue "asset_name" [qty=1] [to_address=""] [change_address=""] [units=0] [reissuable=true] [has_ipfs=false] [ipfs_hash=""]

Issues a new asset on the Ravencoin blockchain.

Usage: transfer "asset_name" qty "to_address" [message=""] [expire_time=0]

Transfers a specified quantity of an asset to a given address.

Usage: listassets [asset="*"] [verbose=false] [count=MAX] [start=0]

Lists all assets, or a specific asset if provided.

Usage: info

Displays information about the RavenDB node.

Usage: stats

Shows server statistics.

Usage: log <on|off|http-on|http-off|none|operations|information>

Manages logging settings.

Usage: gc <0|1|2>

Triggers garbage collection.

Usage: restartServer

Restarts the RavenDB server.

Usage: resetServer

Resets the RavenDB server (use with caution).

Usage: generateClientCert <name> <path> <months> [password]

Generates a client certificate.

Usage: trustServerCert <name> <path> [password]

Trusts a server certificate.

Usage: getnewaddress

Generates a new wallet address.

Usage: sendtoaddress "address" amount

Sends a specified amount of RVN to a given address.
